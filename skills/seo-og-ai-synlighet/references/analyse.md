# Analyse før man bygger

Lag `ANALYSE.md` med disse kapitlene. Alle tall med kilde og dato; antakelser merkes **(antakelse)**.

1. **Kort oppsummering** – 5 punkter: marked, pris, margin, sesong, domene.
2. **Markedet i tall** – befolkning/husstander (SSB), forbruk, sesong (Google Trends: når toppen er).
3. **Konkurrenter og pris** – tabell med pris levert for vanlige mengder; hvor vi er billigst.
4. **Domene** – sjekk ledige navn direkte (Norid: rdap.norid.no). Velg kort navn med produkt + sted, uten bindestrek, som ikke kan forveksles med konkurrent. Vær ærlig: søkeord i domenet gir lite direkte rangering, men flere klikk og lettere å huske.
5. **Hva nettsiden gjør** – tabell «Tiltak → hvorfor».
6. **Gratis tiltak først** – bedriftsprofil, anmeldelser, lenker fra egne sider, kataloger, lokale grupper.
7. **Betalt reklame** – kostnad per bestilling, med antakelser. Skaler først når vi vet hva én bestilling koster.
8. **Plan for de neste ukene** og **hva vi måler hver uke**.
9. **Må avklares** med kunden/bedriften.

Søkeord: tenk «{produkt} {sted}», «kjøp {produkt}», «{produkt} levering», «{produkt} pris», og spørsmål folk stiller («hvor mye … trenger jeg», «er X billigere enn Y»). De siste blir artikler.
